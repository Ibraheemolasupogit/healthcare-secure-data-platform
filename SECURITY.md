# Security policy

Do not open a public issue containing a vulnerability, secret, identifier, or sensitive dataset. Report concerns privately to the repository owner through GitHub's private vulnerability reporting feature.

This repository accepts synthetic data only. If real or plausibly real patient data is found, stop processing, do not copy it, restrict access, notify the owner, rotate any exposed credential, preserve minimal audit evidence, and follow the organisation's incident process. Milestone 1 has no deployed service and makes no security certification claim.
