# Incident readiness boundaries

Incident readiness in this repository means controlled local classification and
routing metadata.

Included:

- incident categories and severity definitions;
- controlled incident lifecycle transitions;
- owner and escalation metadata;
- runbook selection;
- post-incident review structure;
- local incident evidence.

Excluded:

- live alert delivery;
- live ticket creation;
- on-call scheduling;
- SIEM integration;
- production incident response claims;
- clinical-severity classification.
