# Billing identifier conventions

Billing identifiers are synthetic, stable and domain-prefixed.

| Dataset | Prefix |
|---|---|
| `payers` | `PAYR` |
| `services` | `SRV` |
| `products` | `PRD` |
| `tariffs` | `TRF` |
| `contracts` | `CTR` |
| `billable_activity` | `BACT` |
| `claims` | `CLM` |
| `claim_lines` | `CLML` |
| `invoices` | `INV` |
| `invoice_lines` | `INVL` |
| `payment_attempts` | `PATM` |
| `payments` | `PAY` |
| `refunds` | `REF` |
| `adjustments` | `ADJ` |
| `billing_exceptions` | `BEX` |
| `revenue_events` | `REV` |
| `outstanding_balances` | `BAL` |
| `daily_control_totals` | `CTL` |

Identifiers are generated by the existing `stable_id()` helper and are never real payer, invoice, bank, card or patient identifiers.
