# Data classification taxonomy

The central taxonomy lives in `governance/registry/classifications.yaml`.

It reconciles existing repository labels into controlled classes such as public reference,
internal operational metadata, synthetic direct identifiers, synthetic quasi-identifiers,
synthetic health confidential, synthetic financial confidential, research restricted,
model governance, security audit, secret metadata and prohibited secret values.

The repository is synthetic only, but synthetic records still carry privacy and security
controls because linkage, disclosure and misuse patterns can still be demonstrated.
