# Dataiku feature specifications

Milestone 11 defines model-specific features for billing exception prioritisation.

Examples include exception type, affected object type, severity, value at risk, exception age, recurrence count, owner group, source system, payer type, contract type, timing-difference flag, control status, unresolved dependency count and currency.

Feature definitions live in `dataiku/projects/healthcare_analytics/features/billing_exception_features.yaml`.

These are not a governed feature store. Reusable candidates are flagged for Milestone 12 review only.
