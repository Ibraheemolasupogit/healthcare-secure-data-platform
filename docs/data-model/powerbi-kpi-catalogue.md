# Power BI KPI catalogue

The KPI catalogue is source-grounded and synthetic-portfolio specific. It does not define
NHS, statutory, contractual, audit or regulatory standards.

Initial KPIs:

- Attendance Rate;
- Collection Rate;
- Control Pass Rate;
- Revenue at Risk.

Each KPI declares the business question, source measure, target, warning and critical
thresholds, direction, owner, refresh group, dimensional slicing, exclusions, source model,
limitations and synthetic portfolio classification.
