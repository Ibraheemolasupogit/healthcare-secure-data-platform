# Recovery manifest model

`recovery/reference/recovery_manifest.json` records recovery ID, incident/scenario IDs,
symbolic regions, tier, affected services, release ID, commit SHA, plan checksum status,
policy-registry checksum, recovery point, RTO/RPO targets, simulated duration, status,
approval state, validation results, failback status, evidence references, limitations and
synthetic flag.

No live failover, replication or recovery execution is represented by the manifest.
