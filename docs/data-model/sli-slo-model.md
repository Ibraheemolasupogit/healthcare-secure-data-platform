# SLI and SLO model

Milestone 17 defines SLIs for pipeline success, freshness, contract validation,
tests, reconciliation controls, critical exceptions, feature freshness, model
output validation, semantic refresh, deployment validation, evidence checksums
and recovery readiness.

SLOs are synthetic targets used to show operating expectations and error-budget
calculation metadata. They are not production commitments, SLAs or compliance
claims.

Error budgets are metadata-only calculations and are not enforced against live
systems.
