# Milestone 14 evidence

Milestone 14 implements a central governance/security/privacy-control registry.

Evidence covers data domains, classifications, sensitivity levels, personas, purposes,
access policies, separation-of-duties rules, consent policies, masking, row/object access,
export, retention, audit events, service identities, privileged-access controls, platform
mappings, control-framework mappings, persona simulations, sensitive-field coverage,
unsupported-claim scanning, deterministic reference outputs and checksums.

- Entra ID: not connected.

- Dataiku: not connected.
- Fabric/Power BI: not connected.

Enforcement status: not live-enforced.

Certification status: not certified.

Milestone 15 hand-off: CI/CD, protected release controls and deployment evidence can use
the M14 registry as policy input without changing ownership of existing platform layers.
