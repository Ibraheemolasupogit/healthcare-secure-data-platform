# Research access model

Research use follows request, review, provision, monitor and revoke stages. A request states purpose, legal/ethical basis, cohort, fields, duration, destination and outputs. Data governance and an accountable clinical/data owner approve the minimum necessary dataset; higher-risk work requires specialist review.

An approved researcher receives a time-bound functional role and isolated project workspace. Cohort membership is enforced with row-access policy; direct identifiers are excluded by default; sensitive values are tokenised, masked or generalised. Researchers cannot administer policies, grant roles, query raw identifier stores or create uncontrolled external integrations.

Queries, grants, exports and policy decisions are auditable. Output disclosure checks apply before release. Access expires automatically and is reviewed on purpose change. Emergency revocation and incident escalation are documented. Milestone 1 defines this target process only.
