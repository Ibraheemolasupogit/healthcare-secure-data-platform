# Terminology mapping

The lightweight versioned mapping foundation converts selected portfolio codes for sex, encounter class, appointment status and consent status. Existing synthetic ethnicity, organisation/provider, pathology and medication codes are retained with explicit namespaces.

These mappings are not authoritative SNOMED CT, ICD-10, OPCS, LOINC, dm+d, NHS Data Dictionary or FHIR terminology. Future production work requires licensed terminology content, effective dates, clinical governance, a terminology service and unmapped-code operations.
