# Dataiku model monitoring

Monitoring blueprint covers schema validity, missingness, category and numeric distributions, data drift, prediction drift, score distribution, calibration when labels arrive, subgroup performance, model age, feature-set version, training-serving skew and scenario failures.

Retraining is not automatic. Triggers require human review and include metric deterioration, calibration deterioration, sustained drift, class-distribution change, feature-definition change, upstream contract change and governance review.
