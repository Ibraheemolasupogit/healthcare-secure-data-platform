# Golden-path demo

Run:

```bash
healthcare-platform demo run-golden-path
```

The golden path validates synthetic data, interoperability contracts, Snowflake
metadata, dbt layers, assurance, Airflow, Dataiku, feature store, Power BI,
governance, deployment controls, recovery, operations, incident simulation,
recovery-drill simulation and final portfolio evidence.

The command is deterministic and credential-free. It does not call cloud
services or require live platforms.
