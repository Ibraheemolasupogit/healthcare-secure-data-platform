# Month-end assurance runbook

`month_end_assurance` aggregates daily assurance summaries by month, source system and currency.

Use it to review:

- controls run, passed and failed;
- unresolved exception count;
- total value at risk;
- period-level assurance status;
- evidence pack identifier.

Milestone 9 month-end assurance is a deterministic control summary. It is not a statutory close process, GL posting flow, approval workflow or external finance-system integration.
