# Portfolio demo script

Use this for a 10–15 minute walkthrough.

1. Business context: governed healthcare analytics without real patient data.
2. Architecture: source to consumption plus control overlays.
3. Synthetic data: deterministic clinical, operational and billing fixtures.
4. Interoperability: bounded FHIR-inspired and HL7 validation.
5. dbt healthcare core: conformed entities and contracts.
6. Billing and assurance: finance facts, controls and exceptions.
7. Airflow: orchestration contracts, not domain logic.
8. Dataiku: governed analytics and MLOps blueprint.
9. Feature store: offline reusable features.
10. Power BI semantic model: governed consumption metadata.
11. Governance: central policy registry and access simulation.
12. CI/CD: promotion, drift and rollback controls.
13. Recovery: symbolic active/passive recovery design.
14. Operations: health, incident and drill simulation.
15. Golden path: `healthcare-platform demo run-golden-path`.
16. Limitations and next steps: live deployment requires future approval.
