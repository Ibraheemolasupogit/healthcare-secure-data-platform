# Engineering review guide

Recommended review order:

1. Root README for the platform story.
2. Target-state and end-to-end architecture.
3. Component responsibility and ownership maps.
4. Synthetic data and interoperability fixtures.
5. dbt healthcare, billing, finance and assurance models.
6. Airflow orchestration contracts.
7. Dataiku and feature-store metadata.
8. Fabric/Power BI semantic metadata.
9. Governance, deployment, recovery and operations registries.
10. Portfolio evidence and golden-path report.

Known limitations are intentional: no live cloud deployment, no production SLO,
no compliance certification and no clinical validation claim.
